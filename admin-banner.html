Banner Pengumuman

Kelola banner pengumuman: judul, isi, gambar, tombol aksi, target tampilan, dan jadwal tayang.

Panduan Singkat

Baca dulu sebelum mengisi
  1. Link Gambar harus link langsung ke file gambar (contoh: assets/banner-promo.jpg atau https://domainanda.com/gambar.jpg). Jangan pakai link share Google Drive — biasanya gagal tampil. Cara upload gambar ke folder situs sendiri: buka repo GitHub → folder assets → Add file → Upload files.
  2. Teks Tombol = tulisan yang tampil di tombol (misal "Daftar Sekarang"). Link Tombol = alamat tujuan saat tombol itu diklik. Keduanya boleh dikosongkan kalau banner tidak perlu tombol.
  3. Tampil di menentukan banner ini muncul di halaman mana. Gaya Tampilan menentukan bentuknya: Bar Atas Halaman (memanjang penuh di atas) atau Floating Card (kartu mengambang, biasanya pojok layar).
  4. Jadwal Tayang opsional — kosongkan kalau ingin tayang terus selama status Aktif.
  5. Jika satu halaman menampilkan lebih dari satu jenis konten sekaligus, urutannya selalu: Banner Pengumuman → Konten Video → Materi → File Tools.
