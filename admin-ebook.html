E-Book per Paket

Tentukan paket minimum yang boleh membuka setiap konten E-Book.

Cara pakai: unggah konten lewat menu Konten & Materi, Konten Video, atau File Tools dengan akses "Kamar Private" (disebut Kamar E-Book di website). Lalu atur di sini paket minimum tiap konten. Member dengan paket di bawahnya tidak dapat melihat atau mengunduh konten itu; pembatasan dijalankan di database. Pilih "Semua paket" bila konten boleh dibuka seluruh pemilik E-Book.
