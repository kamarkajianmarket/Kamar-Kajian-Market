Request License

Kelola pengajuan license Kamar Robot dan Kamar Indikator dari member: approve, reject, tahan untuk ditinjau, minta revisi, atau kelola license yang sudah aktif (suspend, revoke, reissue token). Aturan sistem: 1 token hanya untuk 1 akun/broker/server, kode token selalu unik tiap kali diterbitkan, dan setiap member dibatasi kuota token aktif (default 1 — bisa dinaikkan per member di panel detail bila memang berhak pakai lebih dari 1 akun).

Kuota Token Member Ini

Kuota adalah jumlah maksimum token AKTIF yang boleh dimiliki member ini untuk fasilitas ini (bukan jumlah request). Default 1 token per member (1 token hanya berlaku untuk 1 akun/broker/server sesuai pengajuannya). Sistem otomatis menolak pengajuan token baru dari member selama masih ada request yang menunggu diproses, dan otomatis menolak begitu jumlah token aktifnya mencapai kuota di bawah ini. Kalau member ini memang berhak memakai beberapa akun trading sekaligus (misal 5 akun), naikkan kuotanya di sini — member baru bisa mengajukan token tambahan satu per satu, dan tetap harus menunggu approval admin untuk tiap token baru.
Approve akan langsung mengaktifkan license dan membuka akses Download EA/Tools untuk member. Reject/Revision akan mengirim status ke member beserta catatan admin di atas.
