Konten & Materi

Kelola materi edukasi/dokumen: link file, kategori, versi, dan hak akses unduh.

Panduan Singkat

Baca dulu sebelum mengisi
  1. Link Materi harus link langsung ke file (PDF, dokumen, dsb) yang bisa diunduh langsung, contoh: assets/materi-nama-file.pdf atau https://domainanda.com/file.pdf. Jangan pakai link share Google Drive — biasanya gagal diunduh. Cara upload file ke folder situs sendiri: buka repo GitHub → folder assets → Add file → Upload files.
  2. Kategori bebas untuk mengelompokkan materi (misal "Edukasi Dasar", "Analisa Teknikal"), boleh dikosongkan.
  3. Akses Diperlukan menentukan siapa yang boleh mengunduh/melihat materi ini (Publik, Member, atau fasilitas berbayar tertentu).
  4. Tampil di menentukan halaman mana yang menampilkan materi ini (sama seperti Konten Video). Jika Akses Diperlukan dipilih fasilitas berbayar, kolom ini otomatis terkunci ke Dashboard Member — materi berbayar tidak pernah tampil di halaman publik.
  5. Label Versi & Catatan Admin bersifat opsional. Catatan Admin hanya pengingat internal, tidak tampil ke member.
  6. Status Publikasi: Draft = belum tayang, Terbit = tayang, Disembunyikan = pernah tayang lalu disembunyikan. Status Aktif = saklar utama on/off.
  7. Jika satu halaman menampilkan lebih dari satu jenis konten sekaligus, urutannya selalu: Banner Pengumuman → Konten Video → Materi → File Tools.
